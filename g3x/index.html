G3X Touch Trainer — help

Een oefensimulator in de stijl van de Garmin G3X Touch (één scherm, GDU 460-indeling) met een eenvoudig model van een Tecnam P2008 JC MkII (Rotax 912 S). Thuisbasis EBZH Hasselt-Kiewit. Het scherm is, zoals op het echte toestel, Engelstalig. In Verkennen staat het toestel stil op de grond en leer je alle functies kennen (Reset zet de startsituatie terug); in Scenario volg je stappen (Reset scenario = zelfde gegevens opnieuw, Nieuwe gegevens = nieuwe willekeurige waarden).

Het scherm bedienen

  • Tikken op velden: baro, hoogte (cyaan vak), heading (HSI), CRS/DTK, bearing pointers, wind, NAV/COM-frequenties (bovenbalk), transponder, AP-balk (bovenaan PFD), CAS-meldingen (bevestigen), EIS-strook (motorpagina), kaart (features / cursor).
  • Harde toetsen op de bezel (zoals op de GDU 460): NRST en D→ links, MENU en BACK rechts. MENU twee keer opent het Main Menu; MENU één keer geeft de opties van de huidige pagina (en Full Screen PFD / Split Screen / Full Screen MFD). BACK sluit een venster of gaat een pagina terug. Onderaan het scherm: knopfuncties, de knop Messages en de klok; SUSP/OBS verschijnen daar en op de HSI.
  • Linkerknop: buiten = HDG, binnen = ALT. Indrukken wisselt naar BARO/CRS en naar COM1-afstemming. Rechterknop: buiten = kaartbereik of scrollen, binnen = pannen/selecteren; indrukken = cursor aan/uit of Enter.
  • Op de kaart: slepen = pannen, scrollwiel = bereik, tik op een symbool = info met Direct-To.

Waar vind ik wat? (knoppenpaden zoals op de G3X Touch)

QNH / baroTik op het baro-veld onder de hoogtetape → cijfers → Enter (of STD). Ook: linkerknop indrukken tot BARO, dan buitenring draaien.
Heading bugBuitenring linkerknop, of tik op de HSI → waarde → Enter / SYNC.
Hoogte selecterenBinnenring linkerknop, of tik op het cyaan hoogtevak boven de hoogtetape.
COM / NAV afstemmenTik op de standby-frequentie (cyaan, bovenbalk) → toetsenbord of lijst Recent/Nearest → Enter. Tik op de actieve frequentie om te wisselen (XFER). Tik op het label COM1/COM2 voor MIC.
TransponderTik op het XPDR-veld (bovenbalk of rechtsonder op de PFD) → code 0–7 → Enter; modus STBY/GND/ON/ALT, IDENT, VFR.
Direct-ToToets D→ op de bezel → tabblad Waypoint (ID aantikken en typen), Flight Plan, Nearest Airports of Recent → Activate. “Course To” voor een inbound koers; “Stop Navigation” annuleert.
VluchtplanMain Menu → Active Flight Plan → + Waypoint. Tik op een rij: Activate Leg, Direct-To, Insert Before/After, Set Altitude (VNAV), Remove. Menu: Invert, Store, Delete, OBS.
NaderingMain Menu → Procedures (of Tools) (of FPL → PROC) → vliegveld, nadering, transitie → Load / Load & Activate. In de FPL-balk: Activate Approach, Vectors-to-Final, Missed, Remove.
NearestToets NRST op de bezel → tabs Airports / VOR / NDB / VRP / User / Airspace → tik op een rij voor info, Direct-To en frequenties.
KaartRechterknop buitenring = bereik; Menu op de kaart = Orientation, Declutter, Topo, Airspace…; slepen of knop indrukken = cursor (Direct-To, user waypoint, luchtruiminfo).
CDI-bron, bearing pointers, wind, SVT, minimumsTik op het bronlabel links boven de HSI (GPS → NAV1 → NAV2), op BRG1/BRG2 en op het windvak; of Menu op een volledig PFD = PFD Options.
Motor & brandstofTik op de EIS-strook (of Home → Engine): Fuel on Board, Reset Fuel Used, Fuel Selector.
Timer, checklist, instellingen, berichtenMain Menu → Timer / Checklists / Setup / Messages (ook COM 1 Radio, COM 2 Radio, XPDR, Audio Panel, VNAV, Weight & Balance, Backlight Intensity). De knop Messages onderaan knippert bij een nieuw bericht.
Scherm­indelingMENU → Full Screen PFD / Split Screen / Full Screen MFD. BACK sluit een venster of gaat een pagina terug; MENU 2× opent het Main Menu.
SUSP / OBSVerschijnen op de HSI en in de onderste strook wanneer van toepassing (bij het MAP of in een hold; OBS via CRS-veld of FPL-menu).

Let op: de exacte labels en knopposities kunnen per G3X-softwareversie en per installatie (configuratie door de installateur, één of twee schermen, met of zonder autopilot) verschillen.

Een gamepad/joystick werkt ook (assen 0/1 rol/pitch, as 3 gas; knop 0 rem, 1/2 flaps). Op een tablet gebruik je de virtuele stuurknuppel in het paneel.

Wat is vereenvoudigd

  • Navigatiedatabase: beperkte set vliegvelden, VOR/NDB, VFR-punten, luchtruimen en naderingen in België en de grensstreek, deels fictief gemarkeerd. Frequenties en coördinaten zijn bij benadering. Geen magnetische variatie.
  • Vluchtmodel en motorgrenzen zijn indicatief; gebruik altijd de POH van het toestel.
  • Geen weerdatalink, verkeer (ADS-B) alleen gesimuleerd in scenario's, geen kaartabonnementen.
