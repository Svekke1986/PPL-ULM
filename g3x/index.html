G3X Touch Trainer — help

Een oefensimulator in de stijl van de Garmin G3X Touch (twee schermen zoals in OO-KWO: PFD links, MFD met EIS-strook rechts) met een eenvoudig model van een Tecnam P2008 JC MkII (Rotax 912 S). Thuisbasis EBZH Hasselt-Kiewit. De schermen zijn, zoals op het echte toestel, Engelstalig. In Verkennen staat het toestel stil op de grond en leer je alle functies kennen (Reset zet alles terug naar de startsituatie; alleen eenheden, geluid, opgeslagen vluchtplannen en user waypoints blijven bewaard); in Scenario volg je stappen (Reset scenario = zelfde gegevens opnieuw, Nieuwe gegevens = nieuwe willekeurige waarden).

De schermen bedienen

  • Tikken op velden: baro, hoogte (cyaan vak), HSI (CDI-bron GPS/VOR, heading bug, bearing pointers, OBS), CRS/DTK, wind, NAV-frequenties (linksonder op de PFD), CAS-meldingen (bevestigen), EIS-strook (motorpagina), kaart (features / cursor).
  • Buiten de G3X, zoals in OO-KWO: GNC 255 (COM én NAV: C/N wisselt, TUNE-knop zet de standby, ⇄ wisselt, vasthouden = 121.500, MON, OBS/T/F voor de VOR), GTX 335-transponder (ON/SBY/ALT/OFF, cijfers, VFR, IDNT, Flight ID OOKWO), rode LEFT/RIGHT-brandstofkraan, flapschakelaar met lampjes 0 / T / L. RPM, CT, olietemperatuur en brandstof zijn analoge meters. De G3X toont als motorinformatie alleen oliedruk, brandstofdruk, volts en ampères, op de MFD.
  • Twee schermen, zoals in OO-KWO: links de PFD, rechts de MFD met de EIS-strook. Elk scherm heeft zijn eigen knoppen en harde toetsen NRST, D→, MENU en BACK. Met de knoppen boven de schermen (of ⤢ op een bezel) vergroot je één scherm; op een laptop is dat het handigst. MENU twee keer opent het Main Menu; MENU één keer geeft de opties van de huidige pagina. BACK sluit een venster of gaat een pagina terug. Onderaan elk scherm: knopfuncties, de knop Messages en de klok; SUSP/OBS verschijnen daar en op de HSI.
  • Knoppen draaien: sleep met de muis of je vinger rond de knop (buitenring of binnenknop); elke 18° is één stap. Scrollen met het muiswiel boven een knop kan ook; het middelpunt is de drukknop.
  • Knopindeling (de trainer volgt Garmins standaardconfiguratie; een installateur kan dit anders instellen): het label onderaan noemt eerst de binnenknop, dan de buitenring. PFD-scherm: linkerknop Heading (binnen) / Altitude (buiten), indrukken = heading bug sync; rechterknop Course (binnen) / Baro (buiten), indrukken = STD. MFD-scherm: linkerknop Select Page (binnen) / Zoom Map (buiten), indrukken = Main Menu; rechterknop Range (binnen) / Pan (buiten) op de kaart of Scroll/List in lijsten, indrukken = cursor of selecteren.
  • Op de kaart: slepen = pannen, scrollwiel = bereik, tik op een symbool = info met Direct-To.

Waar vind ik wat? (knoppenpaden zoals op de G3X Touch)

QNH / baroTik op het baro-veld onder de hoogtetape → cijfers → Enter (of STD). Ook: buitenring van de rechterknop op het PFD-scherm (Baro) draaien; die knop indrukken = STD (1013 hPa).
Heading bugBinnenknop van de linkerknop op het PFD-scherm (Heading), of tik op de HSI → waarde → Enter / SYNC.
Hoogte selecterenBuitenring van de linkerknop op het PFD-scherm (Altitude), of tik op het cyaan hoogtevak boven de hoogtetape.
COM afstemmenGNC 255 (C/N op COM): TUNE-knop buiten = MHz, binnen = kHz (8,33-stappen) zet de standby; ⇄ wisselt actief en standby (1,5 s ingedrukt houden = 121.500); MON luistert de standby mee.
NAV afstemmenGNC 255: C/N naar NAV, TUNE → standby, ⇄ wisselt; OBS toont/zet de koers met de TUNE-knop, T/F toont TO/FROM. Ook via de NAV1-standbyfrequentie linksonder op de PFD.
TransponderGTX 335: cijfers 0–7 (vier cijfers = nieuwe code), modus ON/SBY/ALT/OFF (GND automatisch op de grond), VFR (7000), IDNT, CLR.
Direct-ToToets D→ op de bezel → tabblad Waypoint (ID aantikken en typen), Flight Plan, Nearest Airports of Recent → Activate. “Course To” voor een inbound koers; “Stop Navigation” annuleert.
VluchtplanMain Menu → Active Flight Plan → + Waypoint. Tik op een rij: Activate Leg, Direct-To, Insert Before/After, Set Altitude (VNAV), Remove. Menu: Invert, Store, Delete, OBS.
NaderingMain Menu → Procedures (of Tools) (of FPL → PROC) → vliegveld, nadering, transitie → Load / Load & Activate. In de FPL-balk: Activate Approach, Vectors-to-Final, Missed, Remove.
User waypointOp de kaart: tik op een lege plek → de kaartpointer (cyaan kruis) staat daar en het menu Map Cursor opent → Create User Waypoint at Pointer → Create. Tik ergens anders om de pointer te verplaatsen; slepen verschuift de kaart; BACK of de knop indrukken sluit de pointer. (Knop indrukken zonder pointer zet hem eerst op het vliegtuig.) Tik je vlak bij een vliegveld of punt, dan krijg je de info van dat punt: zoom dan in. Zonder kaart: Main Menu → User Waypoints → Create User Waypoint: identifier, naam en positie (huidige positie, kaartpointer, breedte/lengte of radiaal/afstand vanaf een waypoint). Verwijderen: tik op het waypoint → Waypoint Information → Delete.
NearestToets NRST op de bezel → tabs Airports / VOR / NDB / VRP / User / Airspace → tik op een rij voor info, Direct-To en frequenties.
KaartRechterknop op het MFD-scherm: binnenknop = bereik (ook de buitenring Zoom Map van de linkerknop, of de knoppen − / + op de kaart); Menu op de kaart = Orientation, Declutter, Topo, Airspace…; slepen of knop indrukken = cursor (Direct-To, user waypoint, luchtruiminfo).
CDI-bron, bearing pointers, wind, SVT, minimumsTik op de HSI → HSI Options (CDI Source GPS / VOR1 / VOR2); ook via het bronlabel links boven de HSI, BRG1/BRG2 en het windvak; Menu op een volledig PFD = PFD Options.
MotorEIS-strook op de MFD (oliedruk, brandstofdruk, volts, ampères); tik erop voor de motorpagina. Toerental, temperaturen en brandstof: analoge meters in het paneel.
Timer, checklist, instellingen, berichtenMain Menu → Timer / Checklists / Setup / Messages (ook VNAV, Weight & Balance, Backlight Intensity). De knop Messages onderaan knippert bij een nieuw bericht.
Scherm­indelingKnoppen Beide schermen / PFD / MFD boven de schermen (of ⤢ op een bezel). BACK sluit een venster of gaat een pagina terug; MENU 2× opent het Main Menu.
SUSP / OBSVerschijnen op de HSI en in de onderste strook wanneer van toepassing (bij het MAP of in een hold; OBS via CRS-veld of FPL-menu).

Let op: de exacte labels en knopposities kunnen per G3X-softwareversie en per installatie (configuratie door de installateur, één of twee schermen, met of zonder autopilot) verschillen.

De toetsen zijn gekozen op hun plaats op het klavier, zodat ze op een Belgisch AZERTY-klavier en op QWERTY dezelfde letter dragen (alleen A/Q, Z/W en M verschillen tussen beide; die zijn daarom vermeden of dubbel toegewezen). Een gamepad/joystick werkt ook (assen 0/1 rol/pitch, as 3 gas; knop 0 rem, 1/2 flaps). Op een tablet gebruik je de virtuele stuurknuppel in het paneel.

Wat is vereenvoudigd

  • Navigatiedatabase: beperkte set vliegvelden, VOR/NDB, VFR-punten, luchtruimen en naderingen in België en de grensstreek, deels fictief gemarkeerd. Frequenties en coördinaten zijn bij benadering. Geen magnetische variatie.
  • Vluchtmodel en motorgrenzen zijn indicatief; gebruik altijd de POH van het toestel.
  • Geen weerdatalink, verkeer (ADS-B) alleen gesimuleerd in scenario's, geen kaartabonnementen.
